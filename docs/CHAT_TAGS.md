# 聊天多标签分类

日期：2026-10-20。

## 关系

采用多对多关系，不是单选分类：

```text
项目群 A → 工作、招聘
同学群 B → 生活、招聘
chat_tags ← chat_scope_tags → source_scopes
```

标签全局共享于微信和 QQ 已选择会话；关联以平台、账号和稳定会话对应的 scope_id 为边界，重名聊天不混用。新会话默认无标签；程序重新发现/选择同一会话不会清空已有分类。

## 界面

进入“聊天订阅 → 已选择的扫描范围 → 编辑配置”：

- 点击已有标签切换多选，输入名称可创建新标签。
- 保存配置后才落库，取消不会创建标签或改变关联。
- 取消一个标签只解除当前会话关联，不影响其他会话，也不删除标签目录。
- 每个聊天最多 20 个标签，每个名称 1–32 字符；去除首尾空白、NFC 规范化，同名不区分大小写复用，保留首次命名。
- 列表显示标签，可按单个标签/未分类筛选，也可在搜索框搜索标签名称。
- 标签是分类信息，与订阅启用、参与全量扫描、事项完成状态互不替代；不自动推断优先级或启动采集。

## API

`GET /api/chat-tags` 返回目录：`[{"id":"...","name":"工作","chat_count":2}]`。

`GET /api/subscriptions` 每个会话增加 `tags: [{"id":"...","name":"工作"}]`。

`POST /api/subscriptions/{scope_id}/settings` 示例：

```json
{
  "enabled": false,
  "full_scan_enabled": false,
  "tags": ["工作", "生活"]
}
```

省略 tags 保留原关联；`tags: []` 清除当前会话关联；null、非文本、超长等输入返回 400。标签和两个扫描选项在同一事务中保存，无部分修改。

本轮不提供全局标签改名/删除、标签层级、按标签自动归并任务、给未选择的发现候选批量打标；QQ 消息适配器仍未接入。
